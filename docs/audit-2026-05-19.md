## Executive summary

This codebase is feature-rich and disciplined where it counts (TDD, four gates, 1,383 tests, real-time stack ships end-to-end), but it has not yet been polished to feel like Slack. Three structural debts explain >80% of the perceptible quality gap:

1. **No design system primitives** until v0.0.44 (this session shipped the foundation).
2. **No motion design system** — 91 keyframes, 6 utility classes, hand-rolled timing per component.
3. **The home shell owns the universe** — `app/home/page.tsx` is 1,779 lines / 114 hooks. Every UX iteration funnels there.

Fixing those three lifts ~60% of the inline-style debt, ~80% of the perceptible motion inconsistency, and unblocks parallel iteration. The realtime stack (v0.0.34–v0.0.41) was the previous milestone; **the UI/UX upgrade is the next.**

This release session shipped **v0.0.43 (foundation)** + **v0.0.44 (Wave 1 design system primitives)**. v0.0.45–v0.0.51 are queued.

## Phase 3 — Root cause & impact analysis

### The five root causes that explain >80% of the gaps

1. **No design system primitives.** Every developer reinvents `<div style={{...}}>` for every panel. Hence 2,254 inline blocks, 91 ad-hoc keyframes, unstyled empty/loading/error states. **Fix once → cascades to ~60% of UI debt.** ✅ Wave 1 shipped v0.0.44.

2. **No motion design system.** 91 `@keyframes` exist; only 6 are exposed as utility classes. Inconsistent timing/easing. **Slack feels "alive" because every motion shares a curve. We don't.** ✅ motion tokens shipped v0.0.44; adoption starts v0.0.45.

3. **The home shell is the universe.** `app/home/page.tsx` 1,779 lines / 114 hooks. Cuts to typing/presence/composer all funnel back here. Splitting unblocks parallel iteration. 📋 queued v0.0.46.

4. **CSS is one file.** 17,753 lines means any selector change is a global concern. No co-location, no module boundaries. 📋 queued v0.0.49.

5. **Realtime stack is half migrated.** WS gateway covers 6 of 8 `PubSubEvent` variants. Typing + presence still legacy. The "instant feel" gap. 📋 queued v0.0.51.

### Emotional / functional gaps users feel

| Slack | AAELink | Why |
|---|---|---|
| "Snappy, instant" | "Functional but loose" | Inconsistent motion + spinner-not-skeleton + 2s typing poll |
| "Polished, complete" | "Powerful but rough" | Empty states + error states + modal transitions |
| "Familiar" | "Almost familiar" | Some Slack idioms mirrored, others paraphrased |
| "Effortless typing" | "Adequate typing" | Composer toolbar styling + send-button animation |
| "Trust the indicators" | "Wait for confirmation" | No optimistic UI animation; `pending` message has no visual weight |

### Real-time data flow

Source-of-truth events live in Redis pub/sub (8 `PubSubEvent` variants). Publishing path: route handler → `pool.query(INSERT)` → `pubsub.publish(topic, event)` → Redis → wsGateway pods → WS clients subscribed to topic. Replay path: client reconnects with `since=lastEventId` → gateway calls `replay.since(topic, since)` → if Redis Streams: `XRANGE`, if memory: ring slice → client receives missed events with `replay: true`.
