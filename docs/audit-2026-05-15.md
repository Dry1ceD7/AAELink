## 🔐 Security & discipline findings

These came out of a route-by-route scan. None block a release on their own; together they are a real "shore up the back end" workstream that should sit at the top of the next milestone.

### P0 — CSRF protection is patchy

- 12 of 236 routes import `verifyCsrf`. Of the routes that export `POST` / `PUT` / `PATCH` / `DELETE`, ~180 do **not** call it.
- Cookies use `SameSite=lax` (per `app/api/auth/login/route.ts:158`), which blocks cross-site POSTs at the cookie level — this is the primary defense and is solid.
- CSRF tokens are belt-and-suspenders; without them a single subdomain take-over or relaxed CORS config (and we have `CORS_ORIGINS` env) becomes a direct write path.

**Recommendation:** raise this to a P1 workstream. Either (a) add `verifyCsrf` calls at the start of every mutation route systematically, or (b) move the check into `tracedRoute` so wrapping a method automatically verifies CSRF on mutating verbs. Option (b) is the smaller change.

### P1 — Audit-log coverage is patchy

- 11 of 236 routes call `writeAuditLog`. Per `.claude/CLAUDE.md` every mutation route should.
- This isn't a security hole — it's a compliance / forensic-trail gap. If something goes wrong in production the trail will be sparse.

**Recommendation:** like CSRF, this can either be done at each route or in `tracedRoute`. Doing it in `tracedRoute` avoids forgetting.

### P2 — 66 probably-orphan API routes

- The detector at `scripts/find-orphan-routes.mjs` flags 66 routes after the public-allowlist filter. Most are intentional Slack-compat parity surface, but a manual review pass to delete confirmed-dead ones is overdue.
- Examples worth a closer look: `/api/admin/feature-flags`, `/api/admin/markdown-config`, `/api/admin/data-residency`, `/api/admin/cluster`, `/api/admin/system`, `/api/admin/jobs`. All exist as full route files; none have a UI consumer in the workspace.

**Recommendation:** do one review pass, delete the unambiguously dead ones, and explicitly comment any that are kept-for-Slack-compat with a `// keep: slack-compat` marker so the detector knows to skip them.
