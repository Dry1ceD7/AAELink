# AAELink v0.0.16-alpha — Channel Archival, Bulk Provisioning & CSRF Hardening

**Released:** 2026-05-07  
**Focus:** Automated channel lifecycle, enterprise user import, CSRF protection, webhook signature verification

---

## 🆕 New Infrastructure Modules (2)

### 1. Channel Archival Engine (`lib/channelArchival.ts`)
Automated lifecycle management for inactive channels:
- **Policy-driven archival** — configurable inactivity threshold (default: 90 days)
- **Grace period warnings** — system messages posted before archival (default: 7 days)
- **Exempt patterns** — glob patterns and explicit IDs to skip (`general`, `it-*`, `hr-*`)
- **Min-member threshold** — skip low-member channels
- **Preview mode** — dry-run without side effects
- **Bulk execute** — archive + warn with audit trail per action

### 2. Bulk User Provisioning Engine (`lib/bulkProvision.ts`)
Enterprise-grade CSV/JSON user import:
- **CSV parser** — auto-maps 20+ column aliases (`username`, `user_name`, `email_address`, etc.)
- **Quoted field support** — handles commas inside quoted CSV fields
- **Conflict resolution** — 3 strategies: `skip`, `overwrite`, `merge`
- **Field validation** — username format, email format, role validation
- **Batch processing** — configurable batch size with progress tracking
- **Preview mode** — validates all rows without writing to DB
- **Auto-join workspace** — optional workspace auto-enrollment
- **Up to 10,000 records** per import

## 🛡️ Security

### CSRF Protection Tests (`tests/csrf.test.ts`)
Full test coverage for the double-submit cookie CSRF pattern:
- Token generation format validation
- Signature verification (constant-time comparison)
- Tamper detection for raw and signature portions
- Edge cases (empty, malformed, wrong-length tokens)

### Webhook Signature Verification API (`/api/webhooks/verify-signature`)
New endpoint for webhook consumers to verify HMAC signatures:
- `verify` — validate a payload signature against a secret
- `generate_secret` — create a new `whsec_` signing secret
