# v0.0.52-alpha — Composer expand mode (Cmd+Shift+F)

**Released:** 2026-05-19

Closes the second composer-polish carve from the audit's F2/F3 item. The composer can now be expanded into a full-panel editor via a toolbar toggle or the Cmd/Ctrl+Shift+F shortcut. Same Slack-flavored "open big composer" experience.

## What changed

### `Composer.tsx` — expand mode

- New local state: `const [expanded, setExpanded] = useState(false)`.
- Footer class now toggles `composer--expanded` alongside the existing `composer--edit` class.
- Toolbar gains a single button next to the attach (paperclip) button: `<Maximize2 />` when collapsed, `<Minimize2 />` when expanded. The button has `aria-pressed={expanded}` and a tooltip that names the shortcut.
- Two new keys handled inside the existing `onKeyDown` handler (the keyboard handler that already wraps the editor):
  - **Cmd/Ctrl + Shift + F** — toggles expand mode. Captured at the top of the handler so it always wins over autocompletes.
  - **Escape** while expanded — collapses back to the inline composer. Only fires when no autocomplete (mention / emoji / slash) is open, so Esc-to-close-popup still works as before.
- `expanded` added to the `useCallback` dependency array of `onKeyDown` so the closure reads the latest value (lint-clean per `react-hooks/exhaustive-deps`).
- New imports from `lucide-react`: `Maximize2`, `Minimize2`.

### `app/styles.css` — `.composer--expanded` block

- `position: absolute; inset: 16px;` lifts the composer above the timeline as a full-area panel, with a 16-pixel margin so the surrounding layout's edges are still visible.
- `z-index: var(--z-modal, 100)` — sits above the message timeline using the design-token z-scale (modal-level, not popover-level, so autocompletes still stack correctly above an expanded composer when needed).
- `border-radius: 10px`, `border: 1px solid var(--mm-border)`, `box-shadow: var(--surface-shadow-3)` — same elevation language as `<Surface elevated={3}>` for visual consistency with the rest of the design system.
- The Tiptap editor wrap inside an expanded composer becomes `flex: 1; min-height: 0; overflow-y: auto` so long messages scroll instead of pushing the toolbar off-screen.
- `composerExpandIn` keyframes — a 0.985 → 1.0 scale fade-in on entry. 150 ms easing tied to `--motion-fast`.
- `prefers-reduced-motion` guard disables the entry animation entirely (mirrors the v0.0.51 send-button reduced-motion guard).

## How it feels

- Click the Maximize button → composer expands to fill the chat area, slight scale-fade animates in, the body of the editor scrolls instead of pushing the toolbar off-screen.
- Hit Cmd/Ctrl + Shift + F anywhere inside the editor → same toggle.
- Hit Escape while expanded (and no popup is open) → collapses back to inline.
- All existing toolbar buttons (bold, italic, mention, emoji, attach, send) work identically in both modes.
