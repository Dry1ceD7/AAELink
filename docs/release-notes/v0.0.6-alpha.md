# AAELink v0.0.6-alpha

Release notes for tag `v0.0.6-alpha`.

## Highlights

This release closes **5 major Slack parity gaps**: Advanced Search with operators, Do Not Disturb scheduling, Custom Emoji management, Slash Commands (built-in + custom registry), and server-side Message Drafts. Combined with the v0.0.5 infrastructure features (rate limiting, feature flags, default channels), AAELink now covers the majority of day-to-day messaging functionality found in Slack.

## What is new

### Advanced Search with Operators
- **API**: `GET /api/search/advanced?q=...&workspace_id=...`
- **Slack-style search operators** parsed from the query string:
  - `from:username` — filter by message author
  - `in:#channel-name` — filter by channel
  - `has:link` — messages containing URLs
  - `has:reaction` — messages with reactions
  - `has:pin` — pinned messages
  - `before:YYYY-MM-DD` / `after:YYYY-MM-DD` — date range filtering
  - `is:thread` — only thread replies
- Remaining text after operator extraction is used as keyword search.
- Pagination via `limit` + `offset` with total count.
- Respects channel access: public channels visible, private channels require membership, DMs only for participants.

### Do Not Disturb (DND) Schedule
- **API**: `GET/PUT/POST /api/dnd`
- **Schedule mode**: Set daily DND window with start/end times (HH:MM) and timezone.
- **Quick snooze**: `POST /api/dnd { duration_minutes }` — snooze for 1–1440 minutes.
- **End snooze**: `POST /api/dnd { action: "end_snooze" }`.
- **Real-time status**: API returns `is_active` and `is_snoozed` computed at query time.

### Custom Emoji Management
- **API**: `GET/POST/DELETE /api/emoji`
- Workspace-scoped custom emoji with name validation (`a-z0-9_-`, 2–64 chars).
- Supports both image URLs and alias references to existing emoji.
- Duplicate name prevention per workspace.
- Delete restricted to emoji creator or workspace admins.
- Audit logging on deletion.

### Slash Commands (Built-in + Custom Registry)
- **API**: `GET/POST /api/slash-commands`
- **10 built-in commands**:
  - `/shrug` — Append ¯\\\_(ツ)\_/¯ to message
  - `/dnd [minutes]` — Quick-snooze DND (integrates with DND API)
  - `/status [:emoji:] [text]` — Set user status
  - `/who` — List channel members
  - `/topic [text]` — Set channel topic/purpose
  - `/remind`, `/mute`, `/invite`, `/leave`, `/giphy`
- **Custom command registration**: Workspace admins can register commands with webhook callback URLs.
- Name conflict prevention (cannot shadow built-in commands).

### Message Drafts (Server-side Persistence)
- **API**: `GET/PUT/DELETE /api/drafts`
- Drafts auto-save per user × channel × thread (unique constraint).
- `PUT` with empty body auto-deletes the draft.
- 40,000 character limit per draft.
- Cross-device sync — drafts persist across browser sessions and devices.
- `GET` supports filtering by `workspace_id` or `channel_id`.

## Parity progress

After v0.0.6-alpha, the parity map shows:
- **Messaging core**: 10/12 features shipped (search, pins, saved, drafts, link unfurls all now shipped)
- **Notifications**: DND schedule now shipped
- **Apps & automation**: Incoming/outgoing webhooks + slash commands all shipped
- **Remaining gaps** (deferred to future milestones): Keywords, Bot OAuth, Event subscriptions, Voice/Video, DLP

## Known issues

- Advanced search uses `ILIKE` which doesn't leverage full-text indexes — at scale, migrate to `tsvector` or OpenSearch.
- Custom emoji images must be externally hosted (no direct upload to MinIO in this release).
- Slash command `/giphy` returns a placeholder; Giphy API integration requires an API key.
- DND timezone calculation uses server timezone as a fallback; proper IANA timezone resolution requires `Intl.DateTimeFormat` support.
