# v0.0.24-alpha — Slack-class named themes

**Released:** 2026-05-15

This release ships the **named theme palette** layer that's missing from
v0.0.23. Slack-class users expect to pick "Aubergine" or "Forest" — not
just "Light/Dark". Now they can.

## What changed

### New: 12 named palettes

`lib/themePalette.ts` is the canonical Slack-class palette catalogue:

| Key | Label | Preferred mode |
|-----|-------|----------------|
| `default-light` | Default · Light | light |
| `default-dark` | Default · Dark | dark |
| `aubergine` | Aubergine | light |
| `banana` | Banana | light |
| `forest` | Forest | dark |
| `hoth` | Hoth | light |
| `mint` | Mint | light |
| `nocturne` | Nocturne | dark |
| `ochin` | Ochin | light |
| `terminal` | Terminal | dark |
| `wartocks` | Wartocks | dark |
| `workhaus` | Workhaus | light |

Each palette ships nine CSS variables that override sidebar / workspace-rail
chrome on top of the existing light/dark mode. Users can mix and match —
e.g. Workhaus palette in dark mode for a high-contrast look.

### Themes tab additions

The Themes tab in PreferencesModal now has three sections:

1. **Mode** — Light / Dark / System (existing)
2. **Sidebar palette** — new — 12 colored cards with preview swatches
   (sidebar bg + active pill + mention pill + accent dot). Click any card
   to switch instantly.
3. **Accent color** — existing custom hex picker

### Boot infrastructure

`app/components/ThemeBoot.tsx` now boots both the mode and the palette in
the same `useLayoutEffect` so neither flickers on first paint. The
palette also has a cross-tab `storage` listener so changing the palette
in one tab updates every other tab automatically.

### Tests

New `tests/themePalette.test.ts` (10 tests):
- 12 palettes shipped, all unique keys
- All palettes share the same CSS-var contract
- Every var is a valid 6-char hex
- Catalogue contains the 10 canonical Slack names
- `readPalettePreference` defaults to `default-light`
- `persistPalettePreference` rejects unknown keys
- Round-trips a stored key

Total test count is now **1,326** (was 1,316).
