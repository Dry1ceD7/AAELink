---

## 🆕 New Infrastructure Modules (3)

### 1. Webhook Dead-Letter Queue (`lib/webhookDlq.ts`)
Production-grade webhook delivery reliability:
- **Exponential backoff** with jitter (1s → 2s → 4s → 8s → 16s → 32s)
- **6 retry attempts** before dead-lettering
- **Circuit breaker** per endpoint (auto-disable after N consecutive failures, 5-min cooldown)
- **Dead-letter replay** — manually re-queue failed deliveries
- **Batch processing** with configurable concurrency (default: 5)
- **Auto-purge** delivered/dead items after configurable TTL

### 2. Data Retention Engine (`lib/retention.ts`)
Configurable per-entity data lifecycle management:
- **10 entity types**: messages, files, audit logs, sessions, notifications, typing indicators, read receipts, webhook deliveries, auth codes, OAuth tokens
- **Batch deletion** to avoid long-running transactions
- **Legal hold awareness** (skip held data)
- **Dry-run preview** before executing
- **Custom overrides** per entity at runtime

### 3. IP Access Control (`lib/ipAccess.ts`)
Network-level security middleware:
- **Allowlist + denylist** with CIDR range support (e.g. `10.0.0.0/8`, `192.168.1.0/24`)
- **Private network auto-detection** (RFC 1918)
- **Denylist takes priority** over allowlist
- **Bypass paths** for health/ping endpoints
- **Runtime-configurable** via admin API
