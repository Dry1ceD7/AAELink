# v0.0.48-alpha — LegalHoldPanel stats grid → `<Surface>` cards

**Released:** 2026-05-19

Continues the Wave 2 primitive-adoption sweep. The four-card stats grid in the `LegalHoldPanel` header (Active Holds, Custodians, Total Holds, Exports) now renders via the design-system `<Surface>` primitive instead of repeated inline `border` + `border-radius` + `padding` styles.

## What changed

### LegalHoldPanel — stats grid → `<Surface bordered padded="sm">`

Before, each of the four stat cards was rendered with:

```tsx
<div style={{ padding: 12, borderRadius: 10, border: '1px solid var(--mm-border)', textAlign: 'center' }}>
```

After:

```tsx
<Surface key={s.label} bordered padded="sm" style={{ textAlign: 'center' }}>
```

Wins:

- The token-driven `--surface-radius-md` and `--mm-border` are honored consistently with every other `<Surface>` in the app — no more drift if those tokens change.
- Padding comes from `ds-surface--padded-sm` (8 px), one canonical scale.
- One inline-style block × 4 stat cards collapsed into the primitive (the four loops produce four `<Surface>` instances; the primitive itself owns radius/border/padding).

Inline `style={{ ... }}` block count in `LegalHoldPanel.tsx`: **~50 → ~46**. The remaining inline blocks are:

- The header gradient avatar pill (`linear-gradient(135deg, ...)` background — design-system call needed)
- The hold cards (per-hold expandable card; needs a future `<Card>` or `<Surface>` adoption)
- The settings tab toggles (custom on/off pill — needs a `<Toggle>` primitive)
- A handful of one-off label/value rows

Each remaining block is a discrete carve and will land in subsequent releases.

### Imports

`LegalHoldPanel.tsx` now imports `Surface` alongside the already-adopted `EmptyState`, `Modal`, and `SkeletonStack`:

```ts
import { EmptyState, Modal, SkeletonStack, Surface } from '@/app/components/primitives'
```
