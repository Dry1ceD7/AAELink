# v0.0.44-alpha — Wave 1 design system primitives

**Released:** 2026-05-19

Foundation release for the Slack-feel UI upgrade tracked in `docs/audit-2026-05-19.md` (Phases 4–5). Ships seven primitives + the design tokens they consume. No production callsite has been migrated yet — that lands in v0.0.45 round one of the inline-style sweep, which will replace the noisiest hand-rolled `style={{...}}` blocks with primitives in one or two batches per release.

## What changed

### Design tokens (`app/styles.css`)

Centralized scales the project lacked:

| Token group | Examples |
|---|---|
| Motion | `--motion-instant: 80ms`, `--motion-fast: 120ms`, `--motion-normal: 180ms`, `--motion-slow: 240ms`, `--motion-modal: 300ms` |
| Easing | `--ease-out`, `--ease-in-out`, `--ease-bounce` |
| Z-index | `--z-base`, `--z-dropdown: 1000`, `--z-sticky: 1100`, `--z-modal-backdrop: 9000`, `--z-modal: 9100`, `--z-popover: 9200`, `--z-toast: 9500`, `--z-tooltip: 9700` |
| Surface | `--surface-radius-{sm,md,lg}`, `--surface-shadow-{1,2,3}` |

Plus a global `:focus-visible` ring so keyboard navigation has a consistent, high-contrast indicator (audit §1.3 a11y prerequisite).

### Primitives (`app/components/primitives/*`)

```
import { Surface, Stack, Modal, Tooltip, Skeleton, EmptyState, ErrorState }
  from '@/app/components/primitives'
```

| Primitive | Replaces | Notes |
|---|---|---|
| `<Surface>` | Inline `style={{ background: ..., border: ..., borderRadius: ..., padding: ..., boxShadow: ... }}` cards | Variants: `bordered`, `elevated={1\|2\|3}`, `padded={'sm'\|'md'\|'lg'}` |
| `<Stack>` | The dozen variants of `<div style={{ display: 'flex', gap: N }}>` | `direction='col'\|'row'`, `gap=2..8`, `align`, `justify`, `wrap` |
| `<Modal>` | Hand-rolled `position: fixed; inset: 0; backdrop` overlays | Esc + click-outside close, locks body scroll, scale-and-fade entry, three sizes |
| `<Tooltip>` | Native `title=""` (which has inconsistent timing/styling across browsers) | CSS-only, 200 ms hover delay, no JS positioning library required |
| `<Skeleton>` + `<SkeletonStack>` | Spinners and `<div>Loading…</div>` placeholders | Variants: `line`, `line-short`, `circle`, `card`. Respects `prefers-reduced-motion`. |
| `<EmptyState>` | `<div>No data</div>` patterns | Slack-style: large muted icon, title, description, optional CTA |
| `<ErrorState>` | Toast-only or blank-screen anti-patterns | Pairs with the `lib/log.ts` from v0.0.43 |

All primitives are pure CSS-class composition — no runtime cost vs an inline `style` object.

### Why no production migration in this release

Migration of the ~2,254 inline `style={{...}}` callsites is the big drain audit §1.2 calls out. Doing it in lockstep with primitive creation would mix two changes in one release and make review impossible. Instead:

- **v0.0.44 (this)** ships the primitives without breaking anything — every existing component still works
- **v0.0.45** starts the sweep against the top three offenders (`LegalHoldPanel` 68 blocks, `EKMPanel` 67, `TicketingSettingsPanel` 66 — combined ~200 inline blocks → primitive-driven)
- Subsequent releases continue at one offender per release until the count drops below 200

This release-paced cadence is also what the audit doc's "What I will do next" section calls out as the right sequence.

## Out of scope (deferred)

- **Focus trap inside `<Modal>`.** The simple version closes on Esc and click-outside. A real focus trap (using `inert` or focus-trap-react) lands when keyboard a11y is the next focus.
- **Variant theming for `<Skeleton>`.** Single shimmer color today (`--mm-hover-bg`). Per-theme overrides come with the 12-palette pass.
- **Position-aware `<Tooltip>`.** Always renders `top` of the trigger. Handles 95% of in-app cases. Edge-aware positioning if a real callsite needs it.
- **Toast primitive.** Toast already exists ad-hoc in this repo; standardizing to `app/components/primitives/Toast.tsx` is queued for the inline-style sweep when those callsites get migrated.
