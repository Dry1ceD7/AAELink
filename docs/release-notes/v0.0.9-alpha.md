# AAELink v0.0.9-alpha — Observability & Admin Console Expansion

**Released:** 2026-05-06  
**Focus:** Observability instrumentation, Admin Console UI expansion, Integration Test Infrastructure

---

## Highlights

### 🔭 Observability & Tracing

- **`lib/tracing.ts`** — Lightweight, zero-dependency tracing library
  - W3C `traceparent` header parsing and propagation
  - Per-route latency percentiles: P50, P95, P99
  - Structured JSON logging with trace correlation
  - `withTracing()` convenience wrapper for route handlers
  - Circular buffer for recent span storage (last 500)
  - `metrics.getSystemMetrics()` — uptime, error rate, avg latency
  - `metrics.getRouteMetrics()` — sorted route performance data

- **`GET /api/admin/tracing`** — Observability data API
  - System metrics, route-level performance, recent traces
  - `?view=metrics|traces|all` query parameter
  - `?limit=N` for trace pagination
  - Admin-only access (super_admin, it_admin)

### 🖥️ Admin Console Expansion

**4 new admin panels** (total: 17 admin components):

| Panel | Description |
|-------|-------------|
| `OAuthAppsPanel` | Register OAuth apps, manage client IDs/secrets, revoke tokens, visibility toggles |
| `FunctionsPanel` | Custom function registry, typed JSON schemas, manual execution, execution history |
| `MigrationPanel` | Cross-platform user ID exchange, data import from Slack/Mattermost/Teams/CSV |
| `ObservabilityPanel` | Real-time metrics cards, route latency table (sortable by P95/count/errors), trace waterfall, auto-refresh |

**All panels wired** into `/admin`:
- OAuth Apps & API Tokens
- Custom Functions (register, execute, toggle)
- Platform Migration (super_admin only)
- Observability & Tracing (auto-refresh at 5s intervals)

### 🧪 Integration Test Infrastructure

- **Vitest v4.1.5** installed and configured
- **`vitest.config.ts`** — Node environment, `@/` path aliases, V8 coverage, 15s timeout
- **2 test suites, 30 passing tests:**
  - `tests/tracing.test.ts` — 18 tests: span lifecycle, metrics aggregation, percentile calculation, W3C traceparent, system metrics, reset
  - `tests/platformRole.test.ts` — 12 tests: role hierarchy validation, edge cases (null, undefined, empty string)
- **npm scripts:** `test`, `test:watch`, `test:coverage`
