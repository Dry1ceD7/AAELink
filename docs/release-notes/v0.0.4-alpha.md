# AAELink v0.0.4-alpha

Hand-written release notes for tag `v0.0.4-alpha`. Installers and source: [GitHub Releases](https://github.com/Dry1ceD7/AAELink/releases/tag/v0.0.4-alpha).

## Highlights

This release modernizes the workspace UX to align with enterprise standards (Slack/Mattermost parity), introduces a full-stack Plugin Marketplace, and wires previously placeholder interactions into production-ready components.

## What is new

### Settings Drawer Overlay
- Replaced page-level navigation (`/settings`) with a Slack-style fullscreen in-app drawer overlay.
- Opens from user menu "Profile & preferences", workspace menu "Preferences", and Command Palette (`⌘K → Settings`).
- Supports close via X button, Escape key, or backdrop click.
- Reuses existing `SettingsShell` in `variant="drawer"` — all tabs (Profile, Security, Notifications, Preferences, Updates, Help) work identically.

### Custom Status Popup
- New "Set a custom status" button in the user profile menu.
- Emoji picker (cycle-through), text input (64 char max), and 6 quick-select presets.
- Presets: "In a meeting", "Commuting", "Out sick", "Vacationing", "Working remotely", "Focusing".
- Saves to backend via `PATCH /api/auth/me` (status_emoji, status_text).

### Plugin Marketplace (Full Stack)
- **Database**: Two new PostgreSQL tables — `marketplace_plugins` (published plugins with full metadata) and `installed_plugins` (per-user installations with unique constraint).
- **Backend API**: Five new endpoints:
  - `GET /api/marketplace/plugins` — List all published plugins (with author name resolution).
  - `POST /api/marketplace/plugins` — Publish a new plugin (slug uniqueness check).
  - `GET /api/marketplace/installed` — List user's installed plugins for a workspace.
  - `POST /api/marketplace/install` — Install a plugin (transactional with download counter bump).
  - `DELETE /api/marketplace/install` — Uninstall a plugin.
- **Frontend**: `MarketplacePanel` component with three tabs:
  - **Browse** — Search + category pills + card grid with install/uninstall.
  - **Installed** — Filtered view of user's active plugins.
  - **Publish Plugin** — Form to create and publish custom plugins with emoji icons, hex backgrounds, and versioning.
- **Sidebar**: Added Marketplace module button visible to all workspace members.
- **Command Palette**: Added `Plugin Marketplace` entry with Package icon.

### Invite Members Modal
- Replaced the placeholder invite button with a production-ready modal.
- Auto-generates a 7-day invite link on open via `POST /api/workspaces/invite`.
- Copy-to-clipboard button with visual "Copied!" confirmation.
- Permission-gated: only workspace owners/admins can generate invites.

### Sidebar Customizer
- New "Customize sidebar" dialog accessible from the workspace menu.
- Toggle switches for each sidebar section (Starred, Channels, DMs, Modules, People).
- Persists preferences to localStorage for cross-session consistency.
- Drag handle icons prepared for future drag-and-drop reordering.

## Changed

- All settings entry points (user menu, workspace menu, command palette) now open the drawer overlay instead of navigating to `/settings`.
- `CommandPalette` icon union extended with `marketplace` type and `Package` icon rendering.
- Workspace dropdown "Invite people" now triggers the full invite link flow instead of a no-op.

## Fixed

- Workspace menu "Preferences" was still using `router.push('/settings')` — now correctly opens the settings drawer.
- Workspace menu "Customize sidebar" was a no-op empty handler — now opens the customizer panel.
- Workspace menu "Invite people" had a `/* invite flow */` placeholder — now fully implemented.

## Database migrations

- `aaelink.marketplace_plugins` — Plugin registry with slug uniqueness, emoji icons, category taxonomy, download counters, and rating fields.
- `aaelink.installed_plugins` — User-scoped plugin installations with `UNIQUE(user_id, workspace_id, plugin_id)` constraint.

## Known issues

- Plugin marketplace is UI-complete but plugin runtime sandboxing (actual code execution for installed plugins) is not yet implemented.
- Sidebar customizer toggle state affects visual rendering but full drag-and-drop reordering is a future enhancement.
- Alpha scope: mobile clients, WebRTC video/voice, and plugin code sandboxing are not shipped in this tag.
