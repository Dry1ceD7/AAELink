# v0.0.21-alpha — Slack parity polish & back-end cleanup

**Released:** 2026-05-14

This release focuses on the remaining Slack parity items and back-end
hygiene. Two whole UI components got merged into one; thread management got
the unread/follow polish Slack users expect; mention previews finally appear
on hover; and the call surface gets a proper history view.

## What changed

### Frontend

- **§7.1 — QuickSwitcher absorbs CommandPalette.** There is now a single
  `Cmd+K` / `Ctrl+K` surface. It searches channels, DMs, people, recent
  messages, and **navigation actions** (Tickets, Documents, Preferences,
  Admin, Plugin Marketplace, Workspaces, Keyboard shortcuts, Call history).
  When the input is empty, the most-likely-needed actions show alongside
  recent channels. Action matches are listed before any other result so
  power-users who type "preferences" land on it instantly.

- **§9.1 — User hovercard.** Hover over any `@mention` for 300ms and a
  mini profile card pops up with avatar, presence dot, name/handle,
  job title, role badge, local time (when timezone is known), and quick
  Message / Call buttons. Hovering the card itself keeps it open; mouse
  leave closes it after 150ms grace; Esc dismisses.

- **§6.2 — Thread list unread badges + Mark all read.** `ThreadsListPanel`
  now shows a red "N new" pill on every thread the user is following with
  unread replies, sorts unread threads to the top, adds an "Unread" filter
  tab, and exposes a "Mark all read" button that calls
  `POST /api/threads { workspace_id }`. The button only appears when there
  is something to clear.

- **§13.8 — Call history UI.** New `CallHistoryPanel` (module key `calls`)
  lists every voice / video / huddle / screen-share session with type,
  duration, participant count, start time, and live state. Active rooms
  pin to the top so you can re-join in one click.

### Backend

- **`/api/threads` POST** — bulk mark threads as read across the workspace.
  Bumps `aaelink.channel_read_state.last_read_at` for every channel that
  has a thread the user is following. CSRF-protected, audit-logged
  (`threads.mark_all_read` event).

- **`/api/threads` GET** now returns `unread_count` per thread (replies
  posted by other people after the user's `channel_read_state.last_read_at`).

- **Orphan-route detector hardening** (`scripts/find-orphan-routes.mjs`).
  The detector now matches against trailing path segments and the
  `/api/`-stripped form of each route URL, catching routes that are
  reached through dynamically-built URLs (`apiFetch(\`/api/${kind}/...\`)`)
  that the previous version missed. False positives dropped from 87 → 26
  ("loose-hit only" — flagged separately for manual review). The remaining
  "probably orphan" list is still mostly intentional Slack-compat surface;
  no routes were deleted on the basis of this run alone — manual review
  remains required.

### Cleanup

- **Deleted `app/components/CommandPalette.tsx`.** It had been wired
  through `onCmdPalette`-prop plumbing but no UI surface ever called it
  in production. All of its action items moved into the QuickSwitcher
  `actions` prop. The keyboard trigger (`Cmd+K`) was already QuickSwitcher.

production deployments.
