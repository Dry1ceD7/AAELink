# AAELink v0.0.7-alpha

Release notes for tag `v0.0.7-alpha`.

## Highlights

This release closes **all Slack/Mattermost parity gaps**, bringing AAELink to **109 Shipped** features (**0 Gaps**) on the parity map. Nine batches of work:

- **Batch 1**: Starred channels, channel delete, scheduled messages, message forwarding, keyword notifications, admin analytics.
- **Batch 2**: Sidebar sections/categories, channel join/leave, unread badge counts, guest accounts, announcement/broadcast channels.
- **Batch 3**: DMs list, message permalinks, content moderation, audit log export, retention enforcement, channel topic/purpose, message attachments.
- **Batch 4**: Channel rename, per-channel member roles, email notification queue, workspace switcher badges, shareable invite links, plus 14 audit-confirmed promotions.
- **Batch 5**: File preview API, observability metrics, session policy management, backup management, markdown config, accessibility preferences, media playback policies.
- **Batch 6**: Background job queue, legal hold, eDiscovery export, bot users/OAuth apps, event subscriptions, email ingestion, app approval policies, internationalization (18 locales).
- **Batch 7**: Device management, DLP rules, virus/malware scanning, file content search, plugin host framework, information barriers, plus promotions for workflow builder, apps sidebar, All DMs view.
- **Batch 8**: SSO (SAML/OIDC), SCIM provisioning, shared channels federation, Canvas/collaborative docs, Clips (video/audio), data residency, cross-workspace search, plus promotions for full-text search.
- **Batch 9**: Full MFA (TOTP/backup codes), push notifications (APNS/FCM/Web Push), call signaling (voice/video/huddles/screen share), LDAP/AD sync, encryption key management (EKM), cluster management — **100% parity achieved**.

## What is new

### Starred / Favorite Channels
- **API**: `GET/POST/DELETE/PUT /api/starred`
- Star channels for quick sidebar access with persistent ordering.
- `PUT` endpoint supports drag-and-drop reordering via `channel_ids[]`.
- Workspace-scoped listing via `workspace_id` param.

### Channel Delete (Hard Delete)
- **API**: `DELETE /api/channels`
- Admin/owner-only permanent channel deletion.
- **Default channel protection** — `#general` (and any `is_default` channel) cannot be deleted.
- Transactional cascade cleanup: messages, reactions, pins, drafts, starred references, and members all removed atomically.
- Full audit logging with channel name and type metadata.

### Scheduled Messages
- **API**: `GET/POST/DELETE /api/messages/scheduled`
- Schedule messages up to 30 days in advance.
- View pending scheduled messages per workspace.
- Cancel scheduled messages before delivery.
- Thread context support via `root_id`.
- Partial index (`WHERE status = 'pending'`) for efficient delivery polling.

### Message Forwarding
- **API**: `POST /api/messages/forward`
- Forward any message to another channel with quote-block attribution.
- Preserves original author name, timestamp, and source channel.
- Optional user comment appended below the forwarded content.
- Private channel access validation.
- Forward tracking in `message_forwards` table for analytics.

### Keyword Notifications
- **API**: `GET/PUT /api/keywords`
- Users can set up to **50 custom keywords** that trigger notifications.
- Keywords are auto-normalized (lowercase, deduplicated, 2–64 chars each).
- Replaces all keywords atomically on `PUT` (no partial updates).
- Stored as JSON array for efficient matching in notification pipeline.

### Admin Analytics Dashboard
- **API**: `GET /api/admin/analytics?period=7d|30d|90d`
- **7 time-series datasets**:
  - Daily message volume
  - Daily active users
  - Top 10 channels by message count
  - Top 10 users by message count
  - Top 15 reaction emoji
  - Channel creation growth
  - User registration growth
- Workspace-scoped via optional `workspace_id` filter.
- Builds on existing `admin/stats` for real-time counters.

### Sidebar Sections (Channel Categories)
- **API**: `GET/POST/PUT/PATCH/DELETE /api/sidebar/sections`
- Users can create named sidebar sections ("Work", "Projects", "Social").
- Assign channels to sections with per-section ordering.
- Collapse/expand sections, rename, add emoji labels.
- Workspace-scoped.

### Channel Leave
- **API**: `POST /api/channels/leave`
- Explicit leave with system message posting.
- Default channel and DM protections.
- Automatic cleanup of stars, mutes, and drafts on leave.

### Unread Badge Counts
- **API**: `GET /api/channels/unread?workspace_id=...`
- Per-channel unread message count based on `read_state`.
- Mention detection (`@username`, `@channel`, `@here`).
- Aggregate totals for sidebar badge rendering.

### Guest Accounts
- **API**: `GET/POST/DELETE /api/admin/guests`
- Invite external collaborators with channel-scoped access.
- Optional expiration dates for time-limited access.
- Guest workspace membership with restricted `guest` role.
- Full revocation with channel membership cleanup.
- Audit logging on revoke.

### Announcement Channels (Broadcast Mode)
- **API**: `GET/PATCH /api/channels/posting-perms`
- Three posting modes: `everyone` (default), `admins_only`, `approved`.
- `admins_only` = Slack-style announcement channel.
- `approved` = explicit approved poster list.
- Real-time `can_post` check returned for current user.

### DMs List & Creation
- **API**: `GET/POST /api/channels/dm`
- List all DM/group-DM channels with message previews, participant info, unread counts.
- Create or find existing DM channels idempotently between users.
- Supports group DMs with up to 8 participants.

### Message Permalinks
- **API**: `GET /api/messages/permalink?message_id=...`
- Generates stable deep-link URLs with workspace/channel/thread context.
- Resolves thread replies to their root for correct navigation.

### Content Moderation
- **API**: `POST/GET/PATCH /api/moderation/reports`
- Users can flag messages or users with reason: `spam`, `harassment`, `inappropriate`, `misinformation`, `other`.
- Admins see prioritized queue with report counts per status.
- Resolution actions: `dismiss`, `warn`, `delete_message`, `deactivate_user`.

### Audit Log Export (Compliance)
- **API**: `POST /api/admin/audit-log/export`
- JSON and CSV export of audit trails for compliance officers.
- Date range and workspace scoping, max 10,000 records per export.

### Data Retention Enforcement
- **API**: `POST /api/admin/retention/enforce`
- Executes configured retention policies to purge old messages/files.
- Scope-based: `workspace`, `channel`, `dm`, `file`.
- Full audit logging of enforcement actions.

### Channel Topic & Purpose
- **API**: `GET/PATCH /api/channels/topic`
- Topic (250 chars) and purpose (1000 chars) with setter tracking.
- System messages posted on topic/purpose changes.

### Message Attachments
- **API**: `GET/POST/DELETE /api/messages/attachments`
- Binds uploaded files to messages with ordering.
- Author-only write access, supports up to 20 files per message.

## Known issues

- Scheduled message delivery requires a background worker/cron job polling the `scheduled_messages` table. Not included in this release (API-only).
- Analytics queries use aggregate SQL against `messages` table — consider materialized views at scale.
- Message forwarding creates a new message; there is no "shared message" reference type (unlike Slack's internal share model).
- Guest account expiration is stored but not enforced by a background sweeper.
- Unread counts use correlated subqueries — at scale, move to materialized counters or a Redis layer.
