## Highlights

### 🔑 API Key Management System

**`lib/apiKeys.ts`** — Full lifecycle management for programmatic API access:

- **Key Format:** `aal_<scope>_<hex>` — human-readable prefix indicates permission level
  - `aal_ro_...` — read-only
  - `aal_rw_...` — read + write
  - `aal_adm_...` — admin (implies all)
- **Security:** SHA-256 hashed storage — plaintext returned only at creation
- **Scoped Permissions:** Hierarchical scope system (`read` ⊂ `write` ⊂ `admin`)
- **Expiration:** Optional TTL with automatic validation
- **Usage Tracking:** `last_used_at`, `request_count` updated on every validation
- **Per-Key Rate Limits:** Configurable `rate_limit_per_min` per key
- **Revocation:** Instant key deactivation
- **Database:** New `aaelink.api_keys` table with indexed hash lookups

### 📊 Rate Limit Metrics Collector

**`lib/rateLimitMetrics.ts`** — Observable rate limiting with production dashboards:

| Feature | Description |
|---------|-------------|
| Per-key tracking | Total requests, blocked requests, last seen |
| Route aggregation | Per-route totals, unique keys, block rate |
| Top offenders | Sorted by blocked count for abuse detection |
| Window utilization | Real-time window fill ratio (0.0–1.0) |
| Prometheus export | `aaelink_ratelimit_total`, `_blocked`, `_utilization` |
| Auto-sweep | Stale entries cleaned every 5 minutes |

## API Key Usage

```bash
# Generate a key (POST /api/admin/api-keys)
curl -X POST /api/admin/api-keys \
  -d '{"name": "CI Pipeline", "scopes": ["read","write"], "expires_in_days": 90}'

# Response (key shown ONCE):
# { "key": "aal_rw_a1b2c3d4e5f6...", "id": "...", "scopes": ["read","write"] }

# Use the key:
curl -H "Authorization: Bearer aal_rw_a1b2c3d4..." /api/messages
```
