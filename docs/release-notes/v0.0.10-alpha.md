# AAELink v0.0.10-alpha — Webhook v2, Route Tracing & Grafana

**Released:** 2026-05-07  
**Focus:** Production-grade webhook delivery, route-level tracing, Grafana dashboards, comprehensive test coverage

---

## Highlights

### 🔗 Webhook v2 Delivery Engine

- **`lib/webhookEngine.ts`** — Production-grade outgoing webhook delivery
  - **HMAC-SHA256 signing** with replay attack protection (`X-AAELink-Signature`, `X-AAELink-Timestamp`)
  - **Exponential backoff with jitter** — retry schedule: 1s → 2s → 4s → 8s → 16s → 32s (max)
  - **Event-type filtering** with glob patterns (`message.*`, `channel.created`, `*`)
  - **Rate limiting** per webhook (configurable `rate_limit_per_min`)
  - **Delivery logging** with latency tracking, request/response bodies
  - **Dead letter queue** for exhausted retries
  - **Signature verification** API for consumers (`verifySignature()`)
  - **Delivery statistics** (`getWebhookStats()`) for admin dashboard

- **Worker upgraded** — `webhook_retry` handler now delegates to v2 engine with full HMAC and backoff

### 🔭 Route-Level Tracing Activation

- **`lib/tracedRoute.ts`** — Non-invasive wrapper for Next.js route handlers
  - Auto-creates span with W3C `traceparent` propagation
  - Records HTTP method, URL, status code, latency
  - Injects `traceparent` header into responses for downstream correlation
  - Catches errors and marks spans as failed

- **3 high-traffic routes instrumented:**
  - `GET/POST/PATCH/DELETE /api/channels` — 4 handlers
  - `GET/POST /api/messages` — 2 handlers
  - `POST /api/auth/login` — 1 handler
  - **Total: 7 traced handlers** covering the core request flow

### 📊 Grafana Operations Dashboard

- **`grafana/dashboards/aaelink-operations.json`** — 12-panel dashboard
  - API Request Rate (req/min) with error overlay
  - API Latency (P50/P95/P99) time series
  - Error Rate by Route (table with color-coded thresholds)
  - Job Queue Depth (stacked by status)
  - Webhook v2 Deliveries (stat: total/delivered/failed)
  - Webhook Delivery Latency (gauge with thresholds)
  - DLP Violations (24h stat with alerting colors)
  - Active Sessions (unique users)
  - Audit Log Activity (7d bar chart by action)
  - Workflow Executions (time series by status)
  - Top Routes by Request Volume (bar gauge)
  - System Health (uptime, memory, event loop lag)

### 🧪 Test Coverage Expansion

- **4 test suites, 54 tests** (was 2 suites / 30 tests)
- New suites:
  - `tests/webhookEngine.test.ts` — 12 tests: HMAC signing, verification, replay protection, backoff calculation
  - `tests/emailTemplates.test.ts` — 12 tests: all 8 templates, XSS escaping, HTML structure validation

## Webhook v2 Headers

Outgoing webhook requests include:

```
Content-Type: application/json
User-Agent: AAELink-Webhook/2.0
X-AAELink-Event: message.created
X-AAELink-Delivery: <uuid>
X-AAELink-Timestamp: <unix_ms>
X-AAELink-Signature: sha256=<hmac_hex>
```

Signature is computed over: `{timestamp}.{body}` using the shared secret.
