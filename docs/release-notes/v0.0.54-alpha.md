# v0.0.54-alpha — `<Toggle>` primitive + first two adopters

**Released:** 2026-05-19

Adds an accessible on/off switch to the design system and replaces the per-panel hand-rolled toggle pills in `LegalHoldPanel` and `EKMPanel` settings tabs.

## What changed

### New primitive: `<Toggle>` (`app/components/primitives/Toggle.tsx`)

```ts
export interface ToggleProps {
  checked: boolean
  onChange: (next: boolean) => void
  ariaLabel?: string
  labelledBy?: string
  disabled?: boolean
  danger?: boolean
  className?: string
  style?: CSSProperties
}
```

Built on a `<button role="switch">` with `aria-checked`, full keyboard activation (Enter/Space via the underlying button), and `aria-disabled` semantics. The `labelledBy` prop links the switch to a visible label so screen-readers announce the right text.

Visual contract:

- 44 × 24 px pill (matches the Slack admin toggle proportions)
- 18 × 18 px white knob with a subtle drop-shadow
- Off — `var(--mm-hover-bg)` (neutral)
- On — `#2bac76` green
- On + danger — `#e01e5a` red (for destructive defaults)
- Disabled — `opacity: 0.5; cursor: not-allowed`
- Focus-visible — uses the global `:focus-visible` ring shipped in v0.0.44 (no per-panel ring re-invention)
- `prefers-reduced-motion` — disables the knob slide and background transition

### CSS additions (`app/styles.css`)

A new `Design System Tokens (v0.0.54 Toggle primitive)` block at the bottom of `app/styles.css` defines the `.ds-toggle`, `.ds-toggle--on`, `.ds-toggle--danger`, `.ds-toggle--disabled`, and `.ds-toggle-knob` classes. Knob slide uses `--motion-fast`. Reduced-motion guard collapses both the background and knob transitions to `transition: none`.

### Adopters in this release

**`LegalHoldPanel.tsx` settings tab** — four toggles converted from per-row `style={{ width: 44, height: 24, ... }} > style={{ width: 18, height: 18, ... }}` (4 toggles × 2 nested divs = 8 inline `style={{ ... }}` blocks deleted) to `<Toggle>`. The settings rows themselves also moved from inline `border` + `borderRadius` + `padding` to `<Surface bordered padded="md">`, picking up token-driven radius and border alongside the toggle swap. Local `settings` state introduced (4 keys; placeholder-only — not yet persisted to API).

Settings now actually toggle on/off when clicked, where before they were locked to a hardcoded `i < 2` always-true display state. (The original per-panel UI was a static placeholder; this release upgrades it to a proper controlled switch even though the persistence layer comes in a later release.)

**`EKMPanel.tsx` settings tab** — three toggles converted (one of the four rows is a `<select>` for rotation interval, which stays as-is and gains an `aria-labelledby` for accessibility correctness). Same `<Toggle>` + `<Surface>` + state pattern. Local `ekmSettings` state introduced (3 keys; placeholder).

### Inline-style block reductions

- `LegalHoldPanel.tsx`: ~46 → ~38 inline blocks (settings tab block fully primitive)
- `EKMPanel.tsx`: ~50 → ~44 inline blocks
