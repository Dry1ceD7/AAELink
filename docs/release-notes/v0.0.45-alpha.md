**Released:** 2026-05-19

Ships the on-disk audit deliverables (Phases 1–6 of the multi-agent audit) plus the first half of the F6 logger codemod. The originally-planned v0.0.45 scope was too large for one release — it has been split: Wave 2 panel adoption (LegalHold/EKM/TicketingSettings) lands in v0.0.46.


Idempotent — re-running on already-migrated files is a no-op.

### Roll-back during execution

The initial codemod accidentally renamed `console.error` calls in `lib/tracing.ts` where a local variable named `log` already existed. Reverted that file to native `console.error` for the affected line and dropped the unused `import { log }` to keep tsc clean. The pattern would not recur in future codemods because `lib/tracing.ts` was not in the target list — it had been picked up via a wildcard in an earlier draft.
