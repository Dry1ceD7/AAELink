# v0.0.50-alpha — TicketingSettingsPanel primitive adoption (loading + business-hours surfaces)

**Released:** 2026-05-19

Continues the Wave-2 sweep into `TicketingSettingsPanel.tsx` (517 lines, the SLA + business-hours admin surface). Loading state and the bordered surfaces around the "Add a schedule" form and the seven weekday window cards now use the design system instead of inline styles.

## What changed

### TicketingSettingsPanel adoption

`app/components/admin/TicketingSettingsPanel.tsx` adoptions:

- **Loading state** — was `<div className="doc-muted" style={{ fontSize: 13 }}>Loading ticketing settings…</div>`. Now `<SkeletonStack count={3} variant="card" />`. Slack-style shimmer; respects `prefers-reduced-motion`.
- **"Add a schedule" form container** — was `<div style={{ marginTop: 16, padding: 14, border: '1px solid var(--mm-border-subtle)', borderRadius: 8 }}>`. Now `<Surface bordered padded="md" style={{ marginTop: 16 }}>`. Token-driven radius and border replace hardcoded `1px solid` + `borderRadius: 8`.
- **Weekday window cards (7 of them, Mon–Sun)** — each was `<div style={{ display: 'flex', alignItems: 'center', gap: 6, padding: 6, border: '1px solid var(--mm-border-subtle)', borderRadius: 6 }}>`. Now `<Surface bordered padded="sm" style={{ display: 'flex', alignItems: 'center', gap: 6 }}>`. The 7 cards collapse from per-card inline border + radius + padding to one primitive call each.

### What's intentionally NOT touched yet

- **Business-hours table empty state** — currently a `<tr><td colSpan={4} className="doc-muted">No business-hours schedules yet…</td></tr>` inside a `<table>`. `<EmptyState>` would not nest validly inside a `<tr>`, so the empty cell stays as-is. Future work: split the schedule list out of the table into a card grid that supports `<EmptyState>`, or extend `<EmptyState>` to render as a row.
- **The `<table>` rows themselves** for SLA policies and business-hours schedules — still inline-styled. These would benefit from a `<DataTable>` primitive (audit doc F8 → Wave-3 catalogue), not from per-row `<Surface>` adoption.
- **`PolicyRow`** — table-cell oriented, defers to the future `<DataTable>` work.

### Imports

`TicketingSettingsPanel.tsx` now imports:

```ts
import { SkeletonStack, Surface } from '@/app/components/primitives'
```

### Inline-style block count

`TicketingSettingsPanel.tsx`: **66 → ~57** inline `style={{ ... }}` blocks. The remaining blocks are:

- The header gradient avatar pill / icon containers
- Per-table-row `padding: '8px 4px'` cell styling (defers to future `<DataTable>`)
- A handful of one-off label / textarea / button styling (`fontFamily: 'monospace'`, `width: 90`, etc.) — these are field-specific not container-driven, so primitives don't apply
