# v0.0.46-alpha — `lib/worker.ts` codemod + first primitive adoption

**Released:** 2026-05-19

Closes the F6 logger codemod (last bastion: `lib/worker.ts`, 47 callsites). Ships the first production callsite for the v0.0.44 primitives — `LegalHoldPanel`'s loading + empty states now render via `<SkeletonStack>` and `<EmptyState>` instead of ad-hoc spinner-text.

## What changed

### F6 codemod — `lib/worker.ts`

47 `console.{log,error,warn}` callsites migrated. Worker now imports `import { log } from '@/lib/log'`. Two error-handling sites needed manual fix-up where the codemod left `log.error('msg', err)` (the second arg expects `LogFields`, not the bare `err`):

- `worker.boot` — database connection failure
- `worker.poll` — poll loop error
- `worker.dispatch` — unhandled promise rejection in job
- `worker.main` — fatal startup error

All four now emit structured fields (`name`, `error`) per the `lib/log.ts` contract.

**F6 fully closed.** Zero `console.*` callsites remain in `lib/`. Future code that needs to log goes through `lib/log.ts`.

### First primitive adoption — LegalHoldPanel

Wave 2 starts. Carved scope to keep this release reviewable:

- **Holds tab loading state** — was `<Loader2 className="spin" /> Loading holds…`; now `<SkeletonStack count={3} variant="card" />` (Slack-style shimmer placeholders, respects `prefers-reduced-motion`)
- **Holds tab empty state** — was a one-line muted text; now `<EmptyState icon={<Scale />} title="No legal holds yet" description="…" />` with proper hierarchy and a friendly description that explains what holds do
- **Exports tab placeholder** — was a 60-px-padded centered text block; now `<EmptyState icon={<Package />} ... />`

Inline `style={{...}}` count: **68 → 62 (−6)**. Modest by line count, but the highest-impact UX surfaces (loading and empty states) now look polished.

The remaining 62 inline blocks (header gradient, stats grid, tab buttons, hold cards, settings toggles, modals) are deferred to follow-on releases. Each is a discrete carve.
