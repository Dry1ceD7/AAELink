# AAELink v0.0.2-alpha

Hand-written release notes for tag `v0.0.2-alpha`. Installers and source: [GitHub Releases](https://github.com/Dry1ceD7/AAELink/releases/tag/v0.0.2-alpha).

## What is new

- Service readiness checks and clearer container health routing where the stack reports dependency state.
- Emergency IT support queue from the login screen, with OTP verification for access requests.
- Documents module groundwork: uploads and downloads with PDF-oriented operation queues (preview, OCR, redaction, annotations, forms, signing, export) staged for later milestones.
- Profile avatar uploads up to 20 MB where storage policy allows.

## Changed

- Documentation for local run paths: Docker Compose dependencies plus `npm run dev` / `npm run start` on the host; stack tables aligned with the Next.js codebase in this repository.

## Fixed

- Misleading README instructions that referenced a Task runner, ports, and services not present in the default repository layout.

## Known issues

- Alpha scope: group chat, approvals, knowledge base, calendar, and mobile clients are not shipped in this tag (see root `README.md` roadmap).
