# AAELink v0.0.2-alpha

> **Tag:** `v0.0.2-alpha` &middot; **Channel:** Alpha &middot; **Status:** Feature and hardening update

This alpha expands the platform foundation with stronger service health checks,
isolated emergency support queueing, a dedicated documents module foundation,
and larger profile image support.

---

## What's New

### Platform hardening
- Added separate `/health` and `/ready` endpoints for application services.
- Added container healthchecks for auth, ticket, notify, media, support, documents, frontend, NATS, and Traefik.
- Disabled Traefik's insecure dashboard mode and routed dashboard access through the internal service.
- Added Prometheus scrape targets for the new support and documents services.

### Emergency IT support
- Added a dedicated support service with persistent emergency requests.
- Added a login-screen emergency support panel for users who cannot sign in.
- Queued emergency requests remain available to IT staff through a protected API.

### Documents foundation
- Added an isolated documents service and database schema.
- Added document metadata registration and operation queues for PDF preview, OCR, redaction, annotations, form filling, merge/split, rotation, signing, and export.
- Added a Documents module entry in the app shell with a fault-isolated route.

### Profile assets
- Increased the default profile avatar upload limit from 2 MB to 20 MB.
- Added `MEDIA_MAX_AVATAR_MB` so deployments can tune the avatar limit without code changes.

## Changed
- Frontend and desktop package versions now align to `0.0.2-alpha`.
- Docker build coverage now includes the new support and documents services.
- CI and security workflow matrices now include support and documents services.

## Fixed
- Docker frontend dependency lockfile is synchronized with the Node 22 image used by CI and Compose builds.

## Known Issues
- The documents service currently queues advanced PDF operations; worker-side execution for OCR, redaction, signing, and export is staged for the next implementation pass.
- Alpha desktop builds remain unsigned, so operating system security prompts may appear during installation.
