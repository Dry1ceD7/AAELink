# AAELink v0.0.3-alpha

Hand-written release notes for tag `v0.0.3-alpha`. Installers and source: [GitHub Releases](https://github.com/Dry1ceD7/AAELink/releases/tag/v0.0.3-alpha).

## What is new

### Messaging & Collaboration
- **Typing Indicators**: Real-time display of who is currently typing in a channel.
- **Scheduled Messages (Send Later)**: Queue messages for future delivery via a date/time picker in the composer.
- **Message Reactions**: Emoji reaction picker on every message with optimistic UI updates and toggle-to-remove.
- **Message Forwarding**: Forward any message to another channel with attribution.
- **Message Drafts**: Auto-save and restore composer content per channel using local storage.
- **Inline Emoji Autocomplete**: Type `:emoji_name` in the composer for inline search and insertion.
- **Message Actions Menu**: "⋮ More" dropdown on hover with Copy Text, Copy Link, Forward, Mark as Unread, and Remind Me (30m/1h/4h) actions.
- **Slash Commands**: Built-in command engine — `/shrug`, `/tableflip`, `/unflip`, `/me`, `/status`, `/dnd`, `/mute`, `/unmute`, `/remind`, `/code`, `/help`. Async commands show ephemeral feedback in the composer.
- **Slash Command Autocomplete**: Typing `/` in the composer shows a filterable popup with all available commands, descriptions, and keyboard navigation.
- **Message Reminders**: "Remind me" from the message actions menu or via `/remind`. Reminders fire as in-app notifications at the scheduled time.
- **Mark as Unread**: Mark any message as unread from the More menu; rewinds the channel read cursor so unread indicators re-appear in the sidebar.
- **@here / @channel / @all Mentions**: Group mention support in the composer autocomplete and message rendering. Group mentions display with amber highlight (Slack-style).
- **Link Preview (URL Unfurling)**: URLs in messages are automatically unfurled with OpenGraph metadata — title, description, image, and domain indicator. SSRF protection blocks private IPs.
- **Channel Header Dropdown**: Click the chevron next to the channel name for Star, Mute/Unmute, Copy Link, Invite People, and Leave Channel actions.
- **Extended Slash Commands**: Added `/topic`, `/join`, `/invite`, `/collapse`, `/expand` to the built-in command engine (now 17 commands total).
- **Join Channel by Name**: New `/join #channel-name` slash command + API endpoint for joining public channels.
- **Notification Sounds**: Web Audio API notification chime (Default/Subtle/None) with volume control. No external audio files needed.
- **Notification Sound Settings**: Configurable from Settings → Notifications with live preview.
- **Message Timestamp Tooltip**: Hovering the time on any message shows the full date, time, and day of week (Slack-style).
- **Jump to Latest Button**: Floating "↓ Jump to latest" pill appears when scrolled >200px from the bottom. Animated slide-up entrance.
- **New Messages Separator**: Red "NEW MESSAGES" divider line appears at the first unread message from other users when scrolled away. Click to dismiss.
- **Channel Archive/Unarchive**: Archive channels via the header dropdown or `/archive` command. `/unarchive` to restore.
- **Channel Rename Command**: `/rename [name]` to rename the current channel inline.
- **Who Command**: `/who` lists all members of the current channel.
- **User Profile Local Time**: Hovering a user shows their local time (computed from timezone), DND badge, and enhanced status.
- **21 Slash Commands**: Full command engine with autocomplete — `/shrug`, `/tableflip`, `/unflip`, `/me`, `/status`, `/dnd`, `/mute`, `/unmute`, `/remind`, `/topic`, `/join`, `/invite`, `/archive`, `/unarchive`, `/rename`, `/who`, `/collapse`, `/expand`, `/code`, `/clear`, `/help`.
- **Channel Browse Modal**: Discover and join public channels via searchable modal. Shows channel name, purpose, member count, and one-click join.
- **Auto-Away on Idle**: Presence automatically switches to "away" after 5 minutes of inactivity (1 minute when tab is hidden). Restores to "online" on user activity.
- **Do Not Disturb Schedule**: Configure recurring DND hours in Settings → Notifications. Notifications are suppressed during the scheduled window (supports overnight windows like 10 PM → 8 AM).
- **Search Result Highlighting**: Search matches in GlobalSearchModal are now highlighted with yellow `<mark>` tags for instant visual identification.
- **Thread Follow/Unfollow**: Follow/Unfollow button in the ThreadPanel header. Following shows BellRing icon; clicking toggles subscription.
- **Custom Emoji Management**: Full upload/search/delete panel for custom workspace emoji. Accessible from workspace menu → "Custom emoji".
- **Channel Leave Confirmation**: Leaving a channel now shows a confirmation dialog with channel name and rejoin info.
- **Sidebar Channel Tooltips**: Hovering a channel in the sidebar shows its purpose/description in a native tooltip.

## Changed

- Channels API now returns `purpose` and `header` fields for inline topic display.
- PATCH `/api/channels` extended to support topic/header editing alongside archive/unarchive actions.
- Keyboard shortcuts modal updated to reflect actual implemented bindings (Quick Switcher replaces old command palette reference).
- Removed duplicate ⌘K handler that previously conflicted between command palette and Quick Switcher.

## Fixed

- Composer JSX nesting error caused by orphan closing div tag after drag-and-drop restructuring.
- Duplicate ⌘K keyboard handler causing both command palette and Quick Switcher to open simultaneously.
- Presence SSE reconnect now uses exponential backoff (2 s → 30 s max) instead of a fixed 5-second delay, preventing server hammering during outages.
- Presence SSE server-side tick now guards against concurrent database queries when a slow tick exceeds the 10-second interval.
- "Copy link" in message More menu was generating invalid URLs (pathname never contains `?`); now correctly preserves existing query params.
- Chat message hover timer cleanup on unmount prevents setState-on-unmounted-component warnings.
- Desktop offline page "Connect" button stayed enabled during navigation, allowing double-clicks; now stays disabled.
- Keyboard shortcuts modal used deprecated `navigator.platform`; now uses `navigator.userAgent` with Electron desktop bridge fallback.
- `@mention` and `:emoji:` autocomplete added to the keyboard shortcuts reference.
- Member avatar thumbnails now display in the Channel Info Panel member list (fetched via `avatar_url` join).
- Session Management "Revoke all others" now shows a loading state during bulk revocation.
- Reaction toggle race condition: rapid double-clicks could create duplicate reaction rows; now uses a DB transaction with `ON CONFLICT DO NOTHING`.
- Webhook delete confirmation replaced blocking `window.confirm()` with inline Confirm/Cancel buttons (works in Electron desktop).
- Webhook "Copy token" timer cleanup on unmount prevents setState-on-unmounted-component.
- Threads panel now auto-refreshes on tab focus (matching Tickets panel behavior).
- Login now sets `last_seen_at` immediately so the user appears online right away (previously waited ~45s for first heartbeat).
- Saved Items now pass `message_id` via `focus_msg` query param for scroll-to-message support.

## Known issues

- Alpha scope: approvals, knowledge base, calendar integration, and mobile clients are not shipped in this tag (see root `README.md` roadmap).
- File uploads require `AAELINK_UPLOAD_DIR` environment variable to be set in containerized environments.
- `job_title` and `department` are fully editable by users; future milestone will add admin/HR lock based on `platform_role`.
- Notification schedule suppression is client-side only; server-side cron/worker for push notification suppression is planned.

### Batch 17 — Threads, Reactions, & Session Intelligence

#### Threads API — `is_following` Flag
- **All workspace threads**: GET `/api/threads` now returns all threads in the workspace (up to 100), not just those the user participated in.
- **`is_following` boolean**: Each thread includes a computed flag indicating whether the user authored the root or replied in the thread, enabling the "Following / All Threads" filter in the `ThreadsListPanel` to work properly.

#### Reaction System Expansion
- **Native emoji support**: The reaction validator now accepts both legacy Lucide keys (`thumbs_up`, `heart`, etc.) and native emoji characters (skin tones, ZWJ sequences).
- **Emoji display map**: `reactionToEmoji()` utility resolves legacy keys to their emoji equivalents (e.g., `thumbs_up` → 👍).
- **Universal validator**: `isValidReactionKey()` validates any emoji string up to 20 characters using Unicode Emoji_Presentation detection.

#### Reaction Users API (new)
- **`GET /api/messages/reactions/users?message_id=&key=`**: Returns up to 20 users who reacted with a given key, including `username`, `display_name`, `avatar_url`, and `reacted_at`.
- **Access control**: Verifies the requesting user has channel read access before exposing reactor identities.

#### Session Last Active Tracking
- **`last_active_at` column**: New migration adds the column to the sessions table.
- **Debounced touch**: `readSessionUserId()` now updates `last_active_at` every 5 minutes (fire-and-forget, non-blocking) to minimize write amplification.
- **Sessions API**: GET now returns `last_active_at` and sorts by most recently active.
- **UI**: `SessionManagementPanel` shows relative time ("Just now", "2h ago", "3d ago") instead of absolute login timestamp.

### Batch 19 — Electron Desktop Hardening

#### Offline Page Redesign (`offline.html`)
- **Auto-reconnect**: When redirected from a connection failure, automatically retries after 15 seconds with an animated countdown progress bar.
- **Recent Servers**: Persists up to 5 recently used server URLs in `localStorage`. One-click selection and per-entry removal (×).
- **Cancel retry**: Users can cancel the auto-reconnect countdown at any time.
- **Entrance animation**: Subtle `fadeIn` card animation on load.

#### Window Bounds Persistence (`main.js`)
- **Save/restore**: Window position and size are saved to `window-bounds.json` in the app's user data directory on resize/move (debounced 500ms).
- **Restore on launch**: On next launch, the window opens at the same position and size. Falls back to 1360×880 if no saved bounds.
- **Save on quit**: Bounds are saved during the `before-quit` event as a final safety net.

#### System Idle Detection (`main.js` + `preload.js`)
- **Idle polling**: Checks `powerMonitor.getSystemIdleTime()` every 30 seconds. Broadcasts `aaelink-idle-state` to the renderer when transitioning between `active` and `idle` (5-minute threshold).
- **Lock/unlock detection**: Instantly broadcasts `idle` on screen lock and `active` on unlock.
- **Power events**: Forwards `suspend` and `resume` power events as `aaelink-power-event` so the renderer can reconnect notification/message streams after waking.

#### Preload Bridge Expansion (`preload.js`)
- **`subscribeIdleState(callback)`**: Subscribe to `{ state: "idle" | "active", idle_seconds }` transitions.
- **`subscribePowerEvent(callback)`**: Subscribe to `{ event: "suspend" | "resume" }` system power changes.

### Batch 21 — Session Intelligence, Update API & UI Polish

#### Session Management Enhancement (`/api/auth/sessions`)
- **Device parsing**: User-agent strings are now parsed into `device_type` (`desktop` / `mobile` / `browser`) and `device_label` (e.g. "AAELink Desktop — macOS", "Chrome — Windows", "Safari — iPhone iOS 18.2").
- **Revoke all others**: `DELETE /api/auth/sessions?all_others=1` revokes all sessions except the current one. Returns `{ revoked: N }`.
- **Self-revoke guard**: Attempting to revoke the current session via the DELETE endpoint returns an error with a hint to use `/api/auth/logout` instead.
- **Session count**: Response now includes `count` for UI display.

- **Version comparison**: New `current_version` query param. Response includes `update_available: true/false` based on semver comparison.

- **Asset classification**: Each asset now includes a `platform` field derived from filename patterns (`.dmg` → macos, `.exe` → windows, `.AppImage`/`.deb` → linux).
- **Prerelease flag**: Response includes `prerelease: boolean` from the GitHub release metadata.
- **Content type**: Asset objects now include `content_type` for download handling.
