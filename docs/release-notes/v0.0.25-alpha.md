# v0.0.25-alpha — Manage Sidebar menu, Avatar lightbox, Animation sweep

**Released:** 2026-05-15

Three more parity items from the Slack audit close in this release.

## What changed

### §1.4 — Manage Sidebar menu

New `app/home/ManageSidebarMenu.tsx` mounts as a small gear button at the
top of the scrollable sidebar. Click it for a Slack-class dropdown:

- **Filter** (radio group) — All conversations / Unread only / Active in 30 days
- **Hide muted conversations** (checkbox)
- **Sort A → Z** (checkbox)
- **Show profile pictures** (checkbox)

Prefs persist via `localStorage` (`aaelink-sidebar-manage`) using new
`readManageSidebarPrefs` / `persistManageSidebarPrefs` in
`lib/sidebarSections.ts`. The menu uses `useMenuNav` so all entries are
keyboard-reachable, and `role="menuitemradio"` / `role="menuitemcheckbox"`
for proper ARIA semantics.

ChannelSidebar now applies these prefs at render time:
- `hideMuted` filters muted channels and DMs out of all sections.
- `filterMode === 'unread'` keeps only channels with `unread_count` or `mention_count`.
- `sortAlpha` sorts every section alphabetically by display_name.

### Avatar lightbox

New `app/components/AvatarLightbox.tsx` — full-size profile photo viewer
that opens when a user clicks the avatar in `UserProfileCard`. Includes:
- Backdrop blur + click-to-close
- Esc to close (works even when focus is inside the image)
- Download button that pulls the blob and triggers a save with a clean
  filename (`{user_name}.{ext}`)
- Slack-style scale-in animation honoring `prefers-reduced-motion`

The avatar in `UserProfileCard` now has `cursor: zoom-in` and a
keyboard-accessible `role="button"` wrapper so users tabbing through the
card can open the lightbox with Enter/Space.

### Animation sweep — round 1

Migrated 6 high-traffic components from inline `transition:` strings + 
hand-rolled `onMouseEnter` / `onMouseLeave` handlers to the
`aae-hoverable` utility class introduced in v0.0.23:

- `app/components/SavedItemsPanel.tsx`
- `app/components/FileBrowserPanel.tsx` (list view + grid view)
- `app/components/PeopleDirectoryPanel.tsx`
- `app/components/UserGroupsPanel.tsx`
- `app/components/SlackListPanel.tsx` (table view + list view)

Net effect: the hover feel is now consistent across these surfaces and
honors `prefers-reduced-motion` via the design tokens.

Remaining inline `transition:` strings: 17 in components folder. The
sweep continues as components are touched.
