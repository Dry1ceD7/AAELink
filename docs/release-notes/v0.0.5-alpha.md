# AAELink v0.0.5-alpha

Hand-written release notes for tag `v0.0.5-alpha`. Installers and source: [GitHub Releases](https://github.com/Dry1ceD7/AAELink/releases/tag/v0.0.5-alpha).

## Highlights

This release delivers five major infrastructure and Slack-parity features: a unified **Activity Feed**, **Channel Type Conversion**, **Rate Limiting Middleware**, a **Feature Flag System**, and **Default Channel** auto-provisioning. Together these close the remaining core messaging gaps and establish production-grade API guardrails.

## What is new

### Activity Feed (Slack "Activity" Tab)
- **Backend API**: New `GET /api/activity` endpoint returning a unified, paginated feed of:
  - **Mentions** — Messages containing `@username` across workspace channels.
  - **Reactions** — Emoji reactions on the current user's messages.
  - **Thread replies** — Replies on threads the current user started.
- Supports filtering (`?filter=mentions|reactions|threads|all`), cursor-based pagination (`?before=<epoch_ms>`), and configurable limits (max 100).
- **Frontend Component**: `ActivityPanel` with:
  - Filter pill tabs (All / Mentions / Reactions / Threads).
  - Activity items with avatar, type badge overlay (color-coded: blue for mentions, red for reactions, green for threads), message preview, channel name, and relative timestamps.
  - Click-to-navigate: clicking any activity item opens the relevant channel and scrolls to the message.
  - Infinite scroll "Load more…" pagination.
  - Refresh button and empty states per filter.
- **Sidebar**: The "Activity" navigation button now routes to `module=activity` (previously pointed to `module=notif_schedule`).
- **CSS**: Full BEM-style stylesheet with dark mode support.

### Channel Type Conversion (Public ↔ Private)
- **Backend API**: Extended `PATCH /api/channels` with two new actions:
  - `convert_to_private` — Converts a public channel (`type='O'`) to private (`type='P'`).
  - `convert_to_public` — Converts a private channel back to public.
- Validates channel type before conversion (returns `400` if already target type).
- **Audit trail**: Writes conversion events to `aaelink.audit_log`.
- **Frontend UI**: New button in `ChannelInfoPanel` (About tab) with confirmation dialog.
- **Default channel protection**: Cannot archive or convert `#general` to private.

### Rate Limiting Middleware (New)
- **Next.js Edge Middleware** (`middleware.ts`) applied to all routes, providing:
  - **Tiered rate limits**: Strict for auth endpoints (10/min login, 5/min register), moderate for messages (30/10s), permissive for general API (120/min).
  - **Security headers**: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, and HSTS in production.
  - **CORS**: Configurable via `CORS_ORIGINS` env var, with automatic OPTIONS preflight handling.
  - **Request ID injection**: Every response gets a `X-Request-Id` UUID for distributed tracing.
  - **Rate limit headers**: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, and `Retry-After` on 429 responses.

### Feature Flag System (New)
- **Library** (`lib/featureFlags.ts`): Type-safe feature flag system with three resolution tiers:
  1. Environment variables (`FEATURE_<FLAG_NAME>=true|false`) — highest priority.
  2. Database overrides (`aaelink.feature_flags` table) — cached for 60s.
  3. Compile-time defaults — defined in code.
- Supports both sync (`isFeatureEnabledSync` — client/middleware safe) and async (`isFeatureEnabled` — with DB lookup).
- **30+ flags** pre-defined covering all major feature areas (Huddles, Workflows, Canvas, Marketplace, SSO, DLP, etc.).
- **Admin API** (`GET/PUT /api/admin/feature-flags`): Platform admins can view and toggle flags at runtime with audit logging.

### Default Channel (#general) Auto-Provisioning (New)
- **Helper library** (`lib/defaultChannel.ts`): Ensures a `#general` channel exists for every workspace.
- **Workspace creation**: `POST /api/workspaces` now auto-creates `#general` alongside the existing `all-aaelink` channel, marked with `is_default=TRUE`.
- **Member onboarding**: Admin-created users (`POST /api/admin/users`) are auto-joined to all default channels.
- **Protection**: Default channels cannot be archived (`cannot_archive_default_channel`) or converted to private (`cannot_convert_default_channel`).

## Changed

- Sidebar "Activity" button now uses `module=activity` routing instead of `module=notif_schedule`.
- `PATCH /api/channels` error message for DM modification attempts changed from `cannot_archive_dm` to the more generic `cannot_modify_dm`.
- Admin user creation (`POST /api/admin/users`) now calls `autoJoinDefaultChannels` after workspace member insertion.

## Database migrations

- `ALTER TABLE aaelink.channels ADD COLUMN is_default BOOLEAN NOT NULL DEFAULT false` — Marks auto-join channels.
- `CREATE TABLE aaelink.feature_flags` — Runtime feature flag overrides with `flag_name` uniqueness, `enabled` toggle, and soft-delete (`deleted_at`).
- `CREATE TABLE aaelink.webhook_deliveries` — Tracks webhook execution with status code, request/response bodies, duration, and error messages.

## Known issues

- Activity Feed queries use `ILIKE` for mention detection which may have false positives for common usernames.
- Rate limiting is in-memory (per-process); multi-instance deployments should swap for Redis-backed implementation.
- Feature flag DB cache (60s TTL) means changes take up to a minute to propagate.
- Alpha scope: mobile clients, WebRTC, and plugin sandboxing are not shipped in this tag.
