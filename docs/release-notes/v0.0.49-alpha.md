# v0.0.49-alpha — EKMPanel full primitive adoption (loading, empties, stats, modal)

**Released:** 2026-05-19

Crams a full Wave-2 primitive adoption pass into one panel: `EKMPanel` (Enterprise Key Management) now uses the design system end-to-end for its loading, empty, stats, and add-key-modal surfaces. Same playbook as `LegalHoldPanel` v0.0.46–v0.0.48, executed in a single release.

## What changed

### EKMPanel adoption — all four primitives, one panel

`app/components/admin/EKMPanel.tsx` adoptions:

- **Loading state** — was `<Loader2 size={20} className="spin" /> Loading encryption data…` inside a centered text block. Now `<SkeletonStack count={3} variant="card" />` (Slack-style shimmer placeholders, respects `prefers-reduced-motion`). The `Loader2` import was removed; the spinner is no longer used in this panel.
- **Keys-tab empty state** — was a one-line muted text block. Now `<EmptyState icon={<KeyRound size={40} />} title="No encryption keys configured" description="Add a customer-managed key (BYOK) from AWS KMS, Azure Key Vault, GCP Cloud KMS, or a custom HSM…" />`.
- **Audit-tab empty state** — was `"No key audit events recorded yet."`. Now `<EmptyState icon={<FileText size={40} />} title="No key audit events yet" description="Key creation, rotation, and revocation events will appear here once you start using customer-managed keys." />`.
- **Stats grid (4 cards)** — was per-card `style={{ padding: 12, borderRadius: 10, border: '1px solid var(--mm-border)', textAlign: 'center' }}`. Now `<Surface bordered padded="sm" style={{ textAlign: 'center' }}>` per card. Token-driven radius and border now match every other surface in the app.
- **Add Key modal** — was a hand-rolled `position: fixed; inset: 0; background: rgba(0,0,0,0.5); z-index: 3000;` backdrop wrapping a centered card with header, body, and footer divs. Now a single `<Modal open onClose title footer>` call. Gains: Esc-to-close, body-scroll lock, `role="dialog"` + `aria-modal="true"` + `aria-labelledby`, token-driven `--z-modal-backdrop` / `--z-modal`. The provider list, including the selected-state border and background highlight, is preserved as the modal body content. The `Continue Setup` button now uses `disabled` instead of just opacity-only "looks disabled" styling, so keyboard / screen-reader users get the right semantics.

### Imports

`EKMPanel.tsx` now imports the four primitives:

```ts
import { EmptyState, Modal, SkeletonStack, Surface } from '@/app/components/primitives'
```

`Loader2` removed from `lucide-react` imports (no longer needed once the loading state is a skeleton).

### Inline-style block count

`EKMPanel.tsx`: **67 → ~50** inline `style={{ ... }}` blocks. The remaining inline blocks are:

- The header gradient avatar pill
- Per-key expandable rows (the keys list itself)
- The settings-tab toggle pills (custom on/off — needs a future `<Toggle>` primitive)
- A handful of one-off label/value rows and chips
- The provider-button styling inside the Add-Key modal (kept as-is for the selected state border highlight)

Each remaining block is a discrete carve and queued for follow-on releases.
