# v0.0.47-alpha — LegalHoldPanel modal extraction to `<Modal>` primitive

**Released:** 2026-05-19

Continues the Wave 2 primitive-adoption sweep started in v0.0.46. The "Create Legal Hold" dialog in `LegalHoldPanel` is now driven by the design-system `<Modal>` primitive instead of a hand-rolled fixed-position backdrop. Same look, but Esc-to-close, body-scroll lock, focus-aware aria, and consistent z-index now come from the design system instead of being re-invented per panel.

## What changed

### LegalHoldPanel — Create Hold dialog → `<Modal>`

Before, the create dialog was a roughly 30-line block of inline-styled JSX:

- A `position: fixed; inset: 0; background: rgba(0, 0, 0, 0.5); z-index: 100;` backdrop
- A nested centered card with its own padding, border-radius, max-width
- A header `<div>` with a hand-positioned close button (`<X>`)
- A footer `<div>` with two buttons

After, all of that is one `<Modal open onClose title footer>` call. The form body is the only thing that stays inline-styled, and that's because the input fields are field-specific and don't yet have a `<FormField>` primitive (queued for a future release).

Wins:

- **−20 inline-style lines** in `LegalHoldPanel.tsx`. Inline `style={{ ... }}` block count: **62 → ~50**.
- **Esc-to-close** now works — the previous hand-rolled version had no keyboard handler.
- **Body scroll lock** on open — prevents the background page from drifting when the modal is up.
- **Aria correctness** — `<Modal>` sets `role="dialog"`, `aria-modal="true"`, and links the `aria-labelledby` to the title for screen readers.
- **Z-index consistency** — backdrop and content honor the `--z-modal-backdrop` / `--z-modal` tokens shipped in v0.0.44.

### Imports

`LegalHoldPanel.tsx` now imports `Modal` alongside the already-adopted `EmptyState` and `SkeletonStack`:

```ts
import { EmptyState, Modal, SkeletonStack } from '@/app/components/primitives'
```
