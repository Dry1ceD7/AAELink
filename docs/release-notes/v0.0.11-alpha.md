## Highlights

### 🔐 SCIM v2 Provisioning API

Full RFC 7644 SCIM 2.0 implementation for automated identity lifecycle management from enterprise IdPs (Azure AD, Okta, OneLogin, JumpCloud):

- **`/api/scim/v2/Users`** — 5 methods (GET, POST, PUT, PATCH, DELETE)
  - List/filter users with SCIM filter syntax (`userName eq "john"`, `co`, `sw`)
  - Pagination (`startIndex`, `count`)
  - Create users with auto-generated SSO-only passwords
  - Full replace (PUT) and partial update (PATCH) with JSON Patch operations
  - Soft-delete (deactivate + session revocation) on DELETE
  - Bearer token authentication against `scim_connections` table
  - Sync logging to `scim_sync_log` for audit trail

- **`/api/scim/v2/Groups`** — 5 methods (GET, POST, PUT, PATCH, DELETE)
  - List/filter groups by `displayName`
  - Create groups with auto-generated handles
  - Member management via PATCH operations (`add`, `remove`, `replace` members)
  - Full membership replacement via PUT
  - Hard-delete groups with cascade member cleanup

- **Content-Type:** `application/scim+json` on all responses
- **All 10 handlers are auto-traced** with the `tracedRoute()` middleware

### 📡 Audit Log Streaming Engine

**`lib/auditStream.ts`** — Production-grade SIEM export engine supporting 5 destination types:

| Destination | Format | Auth |
|------------|--------|------|
| **Splunk** | HEC JSON events | `Splunk <token>` |
| **Elasticsearch** | NDJSON bulk API | Bearer token |
| **S3** | JSON Lines (.jsonl) | Pre-signed / token |
| **Webhook** | Envelope JSON | Bearer token |
| **Syslog** | RFC 5424 structured data | N/A |

Features:
- Watermark-based polling (no duplicate exports)
- Configurable batch size and poll interval per stream
- Event action filtering (e.g., only stream `user.*` events)
- Health monitoring via `getStatus()` API
- Graceful start/stop lifecycle
- Database-driven configuration (`audit_stream_configs` table)

## SCIM v2 Usage

### Authentication
```bash
# Create a SCIM connection first (store hashed bearer token)
# Then use the token in API calls:
curl -H "Authorization: Bearer <scim-token>" \
     -H "Content-Type: application/scim+json" \
     https://aaelink.example.com/api/scim/v2/Users
```

### Filter Examples
```
userName eq "john.doe"
email co "example.com"
userName sw "admin"
displayName eq "Engineering"
```
