# v0.0.23-alpha — Single Preferences surface, Slack-class motion utilities

**Released:** 2026-05-15

This release closes the largest "doesn't feel like Slack" gap in the audit
by collapsing the two parallel preferences UIs (`/settings` page and
`PreferencesModal` Cmd+,) into a single Slack-class modal, and adds a
small set of motion utility classes that components can opt into instead
of re-declaring inline `transition:` strings.

## What changed

### Preferences consolidation (P0)

- **One Preferences surface, twelve tabs.** The Cmd+, modal now exposes
  every section a user could need:
  - **Profile** — first/last/display name, pronouns, job title (admin
    only), department (admin only), phone, custom status.
    **Avatar upload** wired via the existing `/api/files/upload` (was
    read-only before this release).
  - **Account & Security** — change password (with show/hide toggle, all
    error states), live "Active Sessions" list with revoke + revoke-all-
    others.
  - **Notifications** — server-side flags (mentions, ticket activity,
    system) + client flags (mute all, typing indicators) + the new
    Slack-style **"Also notify you about"** group: thread replies in
    threads you follow, huddle starts in your channels/DMs, VIP messages
    while DND. Plus weekday-only schedule + active-hours window + keyword
    alerts.
  - **Home** — sidebar layout (DM sort, channel previews) — renamed from
    "Sidebar" to match Slack's term.
  - **Themes** — light / dark / system + accent color picker.
  - **Messages & Media** — message density, avatars, link previews.
  - **Mark As Read** — new tab. Three-way radio for "where to land when
    opening a channel": **Oldest unread** (Slack default), **Most recent**
    (resume scroll), **Newest** (skip past unreads). Plus an opt-in
    "Esc marks all unreads as read" toggle.
  - **Audio & Video** — new tab. Mic / speaker / camera pickers populated
    from `navigator.mediaDevices.enumerateDevices()`. Test-mic and
    test-speaker buttons. Default-mute-on-join, default-camera-on-join,
    noise suppression. Stored in `userPreferences` so when the huddle
    media plane lands the prefs are already wired.
  - **Language & Region** — time format, date format, timezone override
    with auto-detect display.
  - **Accessibility** — UI scale slider, high contrast, reduce motion.
  - **Help & IT** — `EmergencyContactPanel` (verified IT live chat) and
    keyboard shortcut quick reference.
  - **Advanced** — Enter-to-send vs Ctrl/Cmd+Enter, spellcheck, markdown
    preview.

### Removed

- **`app/components/SettingsShell.tsx`** (1,172 lines) — every feature
  migrated to a tab in `PreferencesModal`. Slack has one preferences
  surface; we now do too.
- **`app/home/SettingsDrawer.tsx`** — was a wrapper around SettingsShell
  with no caller. The `settingsDrawerOpen` state was never set to `true`
  anywhere in the codebase.
- **`app/components/SessionManagementPanel.tsx`** (slim variant) — moved
  inline as `InlineSessionsList` inside `PreferencesModal.tsx`. The rich
  admin-page variant in `app/components/admin/SessionManagementPanel.tsx`
  is unchanged.
- The `/settings` page route is now a `redirect('/home?prefs=1')` so any
  bookmark or back-link lands on the unified preferences modal.

### New: motion utility classes (P1)

- `lib/userPreferences.ts` — added 10 new prefs:
  `markAsReadStart`, `escMarksAllRead`, `defaultMuteOnJoin`,
  `defaultCameraOnJoin`, `noiseSuppression`, `preferredMicId`,
  `preferredCameraId`, `preferredSpeakerId`, `notifyThreadReplies`,
  `notifyHuddleStart`, `notifyVipDuringDnd`. All localStorage-backed,
  reduceMotion-respecting where applicable.

- New utility classes in `app/styles.css` (replace inline `transition:`
  scattered across components):
  - `.aae-hoverable` — drop-in hover background + focus-visible outline,
    using `--slack-transition-fast` + `--slack-ease-out`. **Already
    applied** to `ThreadsListPanel` and `CallHistoryPanel` row buttons.
  - `.aae-hover-pop` — Slack-style 1px lift + soft shadow on hover. Honors
    `prefers-reduced-motion`.
  - `.aae-chevron-toggle` — pairs with `aria-expanded` to rotate.
  - `.aae-rhs-enter` — RHS-pane slide-in keyframe.
  - `.aae-pop-in` — popover/hovercard scale-in. Applied to `UserHovercard`.

### Misc

- New radio-button row primitive (`pref-radio` / `pref-radio--active`)
  for the Mark As Read tab — first WAI-ARIA `<fieldset>`/`<legend>` radio
  group in the codebase.
- `pref-pw-form`, `pref-pw-toggle`, `pref-success`, `pref-doc-list` styles
  for the new Account tab and Help tab.
