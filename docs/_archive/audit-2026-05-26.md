## 🔴 Critical Issues

Below are the critical findings that have been identified and remediated.

### CRIT-001 — CSRF Fail-Safe Hardening
* **Location:** `lib/csrf.ts`
* **Evidence:** Fallback secret allowed process to start without configured `CSRF_SECRET`.
* **Recommendation:** Remove fallback and throw error immediately on missing environment variables in production.
* **Inline Fix:** Completed. Lazy `getCsrfSecret()` throws in production when env var is missing; ephemeral per-process secret is used in dev/test.

### CRIT-002 — Authenticate Prometheus Route
* **Location:** `app/api/admin/prometheus/route.ts`
* **Evidence:** Prometheus metrics exposed without strict role authorization.
* **Recommendation:** Authenticate route via Bearer-token + platform-admin session check.
* **Inline Fix:** Completed. Wrapped with `tracedRoute` and added dual-auth via `PROMETHEUS_SCRAPE_TOKEN`.

### CRIT-003 — Shared Worker Database Pool
* **Location:** `lib/worker.ts`
* **Evidence:** Worker instantiated duplicate standalone pools violating pool size constraints.
* **Recommendation:** Route all worker DB interactions through `getPool()` singleton.
* **Inline Fix:** Completed. Replaced parallel pool creation with singleton and cleaned up pool-draining behavior on process exit.

### CRIT-004 — Enterprise Blueprint Framing Correction
* **Location:** `docs/ENTERPRISE-BLUEPRINT.md`
* **Evidence:** Line 558 claimed supersession over BLUEPRINT.md.
* **Recommendation:** Correct framing to align with BLUEPRINT.md as the canonical north star.
* **Inline Fix:** Completed. Replaced supersession claim with companion-document framing.

## 🟠 Required Changes

Remediation stories are queued under `.kiro/stories/`.

### CHG-001 — Split Large Migrations
* **Location:** `lib/migrate.ts`
* **Evidence:** 2,380 lines of inline migration code.
* **Recommendation:** Separate schemas and migrate sequentially using raw sql.

### CHG-002 — Redis Rate Limit Store
* **Location:** `middleware.ts`
* **Evidence:** In-process rate limiter did not share state across server replicas.
* **Recommendation:** Support Redis-backed cross-replica rate limiting with dynamic fallback.

### CHG-003 — Centralized Logger Codemod
* **Location:** 30 callsites using console log directly.
* **Recommendation:** Migrate console.* calls to central logger.

### CHG-004 — Emit Content Security Policy
* **Location:** `middleware.ts`, `lib/csp.ts`
* **Evidence:** Lack of strict security headers on route responses.
* **Recommendation:** Emit strict CSP header on all HTTP responses.

### CHG-005 — Style Sweep
* **Location:** 2,254 inline style blocks across 88 files.
* **Recommendation:** Relocate layout and styles to Tailwind design primitives.

### CHG-006 — Modal Focus Trap
* **Location:** 27 modal/dialog dialog panels.
* **Recommendation:** Add focus trapping to ensure compliance and a11y.

### CHG-007 — Share Database Pool in Tests
* **Location:** `__tests__/helpers.ts`
* **Evidence:** Tests running parallel pool creation causing connection saturation.
* **Recommendation:** Re-route tests through shared `getPool()` singleton.

### CHG-008 — Pin postcss in overrides
* **Location:** `package.json`
* **Evidence:** XSS vulnerability warning in postcss dependency.
* **Recommendation:** Pin postcss to ^8.5.10 in package overrides.

### CHG-009 — Rebuilt Parity Reference Matrix
* **Location:** `docs/parity-reference-matrix.md`
* **Evidence:** Matrix stale since version 0.0.10.
* **Recommendation:** Rebuild 14-category matrix to match live codebase status.

### CHG-010 — Roadmap & ADR Alignment
* **Location:** `docs/ROADMAP.yaml` and `docs/ADR/`
* **Evidence:** Drift between active development path and planning docs.
* **Recommendation:** Standardize YAML schemas and add ADR-0009 through ADR-0013.

### CHG-011 — Home Shell Split
* **Location:** `app/home/page.tsx`
* **Evidence:** 1,808 lines and 114 hooks in single shell page.
* **Recommendation:** Extract hooks and partition UI panels.
