## 🔭 Things that surfaced but are *not* problems

- `as Record<string, unknown>` casts on `pg` rows — by design, narrowed at the
  call-site. Migrating to row-shaped interfaces is incremental tech debt, not
  active risk.
- One `// eslint-disable react-hooks/exhaustive-deps` in `Composer.tsx`,
  `ForwardMessageModal.tsx`, `TicketingSettingsPanel.tsx`, `PuzzleBoxEditor.tsx`
  — each is intentional (fire-once effect or stable ref dep).
- `lib/retention.ts` has `// eslint-disable-next-line no-constant-condition`
  on a controlled batch loop — guarded by an explicit break condition.
- Two `eslint-disable @next/next/no-img-element` in splash loaders — these
  intentionally avoid `next/image` because the splash mounts before the Next
  runtime has hydrated.

## 📋 Recommended follow-ups (P2, not blocking v0.0.20)

1. **Workspace branding admin UI.** The assemble stage now reads from
   `aaelink.workspace_settings.settings.branding`, but there's no panel for
   admins to edit name/address/tax_id/contact yet. Today they're set to
   sensible defaults at render time. Effort: M.
2. **Block-tree versioning UI.** Saves currently always create a new
   `version`; add a "Save in place" mode for tiny tweaks. Effort: S.
3. **Document recognizer.** `BLOCK_LIBRARY[type].recognizer_hints` is
   populated for every block but no scanner consumes them yet. The next
   step is to feed Stirling-PDF OCR coordinates into a hint-matcher and
   propose a starter block tree. Effort: L.
4. **Slot bind picker UX.** The inspector currently shows raw paths
   (e.g. `client.address.line1`) — replace with an autocomplete fed by
   the live ResolveContext keys. Effort: M.
5. **Per-locale string overrides.** `DocumentTree.locale_overrides` is
   reserved in the schema but the editor doesn't surface it yet. Effort: M.
